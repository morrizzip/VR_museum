# VR_museum

## Описание проекта
Данный проект представляет собой VR-решение для иммерсивного представления музейных экспонатов в рамках основной экспозиции МВЦ "Апатит".

## Функциональность
Программа обеспечивает следующий функционал:

*   Управление информацией об экспонатах через веб-интерфейс.
*   Навигация по виртуальному залу.
*   Взаимодействие с отдельными экспонатами.
*   Обучение распилу экспонатов.
*   Получение справочной информации о выбранных экспонатах.

## Технологии
В проекте используются следующие технологии:
*   **Godot Engine 4.6** - движок VR-приложения.
*   **GDScript:** - логика VR-приложения.
*   **OpenXR** - поддержка VR-гарнитур.
*   **Blender** - для разработки 3D-моделей.
*   **Python:** - для разработки веб-части.   
*   **Flask** - веб-сервер и API.
*   **SQLite** - база данных.

## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone [URL репозитория]
    cd [папка_репозитория]
    ```
2.  Для веб-части прочтите README в директории web-server
3.  Подключите VR-гарнитуру к ПК и запустите SteamVR
4.  VR-приложение запустите в Godot 4.6
